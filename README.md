# Energy CRM

Локальное CRM-приложение для самозанятых и ИП: сделки, договоры, акты, журнал НПД и карточки для «Мой налог».

## Возможности

- Данные хранятся в `localStorage` (ключ `energy-crm-data`) — без облака
- Темная / светлая тема
- Заказчики, профили услуг, сделки, журнал, документы
- Генерация договора и акта (скачивание `.doc` / печать)
- Карточка для «Мой налог» с копированием полей
- Экспорт / импорт JSON для переноса между ПК
- Импорт из старого файла `mini-crm-journal-final.html`

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

## Сборка

```bash
npm run build
npm run preview
```

Папку проекта можно скопировать на другой ПК. После запуска на новом компьютере импортируйте JSON-бэкап в разделе **Резервная копия**.

## Перенос данных

1. На исходном ПК: **Резервная копия → Экспорт в JSON**
2. Скопируйте файл `crm-backup-YYYY-MM-DD.json` (и при желании всю папку проекта)
3. На новом ПК: запустите приложение → **Импорт из JSON**

Импорт из HTML: загрузите `mini-crm-journal-final.html` — приложение извлечёт объект `app` и перенесёт данные.

Образцы лежат в `public/`:

- `mini-crm-journal-final.html`
- `sample-backup.json`
